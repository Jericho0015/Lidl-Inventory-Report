# 🛒 Lidl Inventory Insights: Power BI Dashboard
Power BI dashboard providing real-time insights into Lidl’s inventory performance tracking stock levels, revenue, category-wise value, and sales trends to improve inventory management and decision-making.

## Purpose
The Lidl Inventory Dashboard helps business managers monitor inventory turnover, sales performance, and stock availability across regions and product categories. It ensures better demand forecasting, reduced stockouts, and optimized supply chain efficiency.
